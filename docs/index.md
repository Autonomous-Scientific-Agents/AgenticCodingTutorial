# Agentic Coding: Basics and Best Practices

*Genesis Mission Platform — Foundations session F5 · October 15, 2026*

Build with tests, make it fast, give it a face.

!!! abstract "The one idea"
    **You set the goal and the direction. The agent executes. You verify.**
    The agent makes code cheap to write; reviewing, maintaining and trusting it are not.
    Use the agent to raise the bar — better tests, better performance, a better interface — not the line count.

## What you will be able to do

1. Run a coding agent (Claude Code, Codex CLI, OpenCode, Cursor or Kilo Code) on a real repository.
2. Steer it with four layers: instructions (`AGENTS.md` or `CLADUE.md`), skills (`SKILL.md`), memory and permissions.
3. Let tests be the stopping rule, so "done" means the tests pass, not that the agent says so.
4. Go from correct, to fast, to usable, see hands-on demos of the session.
